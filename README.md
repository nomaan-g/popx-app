# PopX Mobile App

A pixel-perfect React implementation of the PopX mobile app design (Adobe XD).

## Screens

- **Landing** — Welcome screen with Create Account and Login actions
- **Login** — Sign in with email and password
- **Signup** — Create account form with agency selection
- **Profile** — Account settings with user details

## Tech Stack

- React 19
- Vite
- React Router DOM

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```

## Deployment

The project is configured for Vercel and Netlify with SPA routing support.
